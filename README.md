# 352 新风 (Fresh Air) for Home Assistant

将 **352 G30 新风机** 接入 Home Assistant 的**纯本地**集成：状态读取 + 控制全部走局域网
UDP（端口 11530），**不依赖 352 云服务器**。

协议通过对官方 App（包名 `com.mxchip.project352`）的逆向分析与**真机实测校准**得到，
详见 [docs/本地UDP协议.md](docs/本地UDP协议.md)。

## 功能

| 实体 | 功能 |
|------|------|
| `fan` | 开关机、预设模式（自动/睡眠/极速/手动）、当前风量百分比（显示） |
| `number` | **风量**滑动条，40–300 m³/h、步进 10（实测直达设备） |
| `switch` | 显示灯 |
| `select` | 辅热 PTC（关/低/高） |
| `sensor` | PM2.5、CO₂、温度、湿度、风量（m³/h） |

状态由设备主动推送（收到订阅请求后每 2~8 秒一帧），控制命令即时下发并乐观刷新 + 催查确认。

## 安装

### 手动
1. 把 `custom_components/air_352/` 复制到 Home Assistant 配置目录的 `custom_components/` 下
2. 重启 Home Assistant
3. 「设置 → 设备与服务 → 添加集成」搜索 **352**

### HACS（自定义仓库）
1. HACS → 右上角 `...` → 自定义存储库
2. 填入本仓库 URL，类别选 **Integration**
3. 安装后重启 HA，再添加集成

## 配置

| 项 | 说明 |
|----|------|
| MAC 地址 | 必填，如 `F0:FE:6B:A5:81:8E`，用于过滤本设备状态帧 |
| Host | **必填**，设备局域网 IP（控制命令发往它；建议路由器做静态绑定） |
| 型号 | `g30` |
| company_code / device_type / auth_code | **设备身份**，默认 `0xF2 / 0x04 / 0xA31A`（本 G30 实测值） |

### ⚠️ 关于设备身份

每台 352 设备的 `companyCode / deviceType / authCode` 不同，且**控制帧身份不符会被设备静默丢弃**
（这是"命令没反应"的最常见原因）。获取方式见协议文档 §2：
从 `wifi.352air.com/api2/device/getDeviceList` 的设备列表，或直接读设备状态帧头 `[12..15]` 字节。

## 已验证（真机）

- 状态推送解析：温度/湿度/CO₂/PM2.5/风量 实时正确
- 电源：`0x5E` `0x00`=开 / `0x11`=关，power 字节实测翻转
- 模式：`0x51` `1/2/3/5` → mode 字节逐一对应
- 风量：`0x58` + 2 字节 m³/h，300 → ws=300 直达
- 帧格式：与实测生效帧逐字节一致（CRC-16/GENIBUS 校验通过）

## 兼容性

当前针对 **G30 新风**（固件身份 `F2/04/A31A`）开发。其他型号（如 X83 净化器 `F1/02/0D0C`）
协议方言可能不同，欢迎按协议文档补充。
